# Side Projects

Personal side projects and coding exercises — separate from my [ai-ml-projects](#) and [cybersecurity-projects](#) monorepos. Each subfolder is self-contained with its own README and dependencies.

## Projects

### [fetch-weather-cli](./fetch-weather-cli)
A Python CLI tool that fetches current local weather conditions for any US street address using the Census Bureau geocoding API and weather.gov — no API key required.

### [portfolio-tracker](./portfolio-tracker)
A class-based Python stock portfolio tracker backed by SQLite. Tracks transactions and cash flows, derives current positions using average-cost accounting, and computes portfolio metrics like unrealized/realized gains, diversification, and ROI.

## Structure

Each project folder is independent — its own README, its own dependencies, its own virtual environment. Nothing here is meant to be installed or run from the repo root.
